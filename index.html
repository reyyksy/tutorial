01

Persiapan

Cek tools terlebih dahulu

Belum punya tools? Pilih cara instalasi di bawah. Setelah selesai, kembali ke bagian cek versi.

WindowsPowerShell

Instal Node.js dan Git lewat terminal:

winget install OpenJS.NodeJS.LTS Git.Git
Instal lewat GUI / browser ↗
LinuxTerminal

Untuk Debian atau Ubuntu:

sudo apt update
sudo apt install -y nodejs npm git
Instal lewat GUI / browser ↗
macOSTerminal

Jika Homebrew sudah terpasang:

brew install node git
Instal lewat GUI / browser ↗

GUI / browser: buka halaman unduhan resmi, pilih installer sesuai sistem operasi, lalu ikuti langkah Next sampai selesai. Git dapat diunduh dari git-scm.com/downloads.

Jika tools sudah terpasang, jalankan perintah berikut. Jika muncul nomor versi, berarti siap digunakan.

Pilih sistem operasiBelum dicek

Jalankan di PowerShell

node --version
npm --version
git --version

Jalankan di Terminal

node --version
npm --version
git --version
02

Unduh source code

Pilih cara yang paling nyaman

Repository resmi aplikasi tersedia di GitHub. Pilih salah satu cara berikut.

⌘Disarankan untuk developer

Clone lewat CLI

Salin repository langsung dari terminal. Cara ini mudah untuk update berikutnya.

gh repo clone reyyksy/absensi

Belum punya GitHub CLI? Gunakan cara Git biasa:

git clone https://github.com/reyyksy/absensi.git
↓Tanpa terminal

Unduh dari GitHub

Cocok jika belum terbiasa memakai command line.

  1. Buka repository di GitHub.
  2. Klik tombol Code.
  3. Pilih Download ZIP.
  4. Ekstrak file ZIP ke folder pilihan.
Buka repository GitHub ↗
03

Instalasi & penggunaan

Pasang dependency, lalu jalankan

Masuk ke folder hasil clone. Contoh di bawah menggunakan folder absensi.

01 / Masuk folder proyek
cd absensi
02 / Install dependency
npm install
03 / Jalankan aplikasi
node src/server.js
i

Setelah server aktif, buka http://localhost di browser.

04

Opsional

Atur password admin

Atur password sebelum menjalankan server. Pilih perintah sesuai sistem operasi.

Windows · sementara
$env:ADMIN_PASSWORD = "passwordbaru"
Windows · permanen
[System.Environment]::SetEnvironmentVariable("ADMIN_PASSWORD", "passwordbaru", "User")
Linux / macOS · permanen
export ADMIN_PASSWORD="passwordbaru"

Ganti passwordbaru dengan password pilihanmu. Perintah sementara hanya berlaku di terminal yang sedang terbuka.
